# 💸 Expense Tracker Pro

A full-stack expense tracker with user authentication, MySQL database, and beautiful charts dashboard.

### ✨ Features
- User Signup / Login (User-wise data)
- Add / Delete Transactions with Category & Payment Method
- Real-time Balance, Income & Expense Calculation
- Beautiful Dashboard with Doughnut & Bar Charts (Chart.js)
- MySQL Integration with Spring Data JPA
- Responsive Premium UI

### 🛠️ Tech Stack
Backend: Java, Spring Boot, REST API
Database: MySQL
Frontend: HTML, CSS, JavaScript, Chart.js
Tools: Maven, Git

### 🚀 How to Run
1. Create MySQL DB `expense_tracker`
2. Update `application.properties`
3. Run `ExpenseTrackerApplication.java`
4. Open `http://localhost:8080/login.html`
